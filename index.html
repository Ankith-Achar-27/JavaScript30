About This Challenge

This repository is part of the JavaScript30 challenge by Wes Bos. The goal is to build 30 projects in 30 days using Vanilla JavaScript, HTML and CSS — without frameworks, compilers or libraries. Each project is an opportunity to practise core JavaScript concepts, improve problem-solving skills and gain hands-on development experience.
