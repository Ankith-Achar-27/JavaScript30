# JavaScript30 – 30 Days of JavaScript

A 30-day coding challenge featuring 30 hands-on projects built using **HTML, CSS, and Vanilla JavaScript**.

This challenge is based on [Wes Bos's JavaScript30](https://javascript30.com/), designed to strengthen core JavaScript concepts through practical, project-based learning.

## Live Demo

**[View My JavaScript30 Portfolio](https://ankith-achar-27.github.io/JavaScript30/)**

## About the Challenge

The goal of this challenge is to improve my JavaScript skills by building 30 projects in 30 days without using frameworks, libraries, or build tools.

Each project focuses on different JavaScript concepts, browser APIs, DOM manipulation, events, and practical frontend development.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
